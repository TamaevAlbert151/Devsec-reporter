# Devsec-reporter 

Простой инструмент для генерации HTML-отчётов по результатам анализа кода, линтинга и безопасности.

---

##  Что это такое

Devsec-reporter — лёгкий Python-скрипт, который:

* читает входной файл `report.json` с результатами проверок;
* извлекает список найденных проблем / предупреждений;
* собирает их в таблицу;
* генерирует HTML-отчёт `report.html`, который удобно открыть в браузере.

Проект спроектирован так, чтобы быть **минималистичным и понятным** — без внешних зависимостей, только стандартная библиотека Python.

---

##  Структура репозитория

```
/
├── run.py         # основной скрипт, который генерирует отчёт
├── report.json    # пример входных данных (можно заменить своим)
└── report.html    # HTML-отчёт (создаётся автоматически после запуска)
```

---

##  Быстрый старт

1. Убедитесь, что у вас установлен **Python 3**.
2. Клонируйте репозиторий или скачайте файлы:

   ```bash
   git clone https://github.com/TamaevAlbert151/Devsec-reporter.git
   cd Devsec-reporter
   ```
3. Проверьте наличие файла `report.json` (можно использовать пример).
4. Запустите скрипт для генерации отчёта:

   ```bash
   python run.py
   ```
5. После выполнения появится файл `report.html`. Чтобы открыть отчёт:

   * На **Windows**: `start report.html`
   * На **Mac**: `open report.html`
   * На **Linux**: `xdg-open report.html`

Откроется браузер с таблицей всех найденных проблем и предупреждений.

---

## Пример `report.json`

```json
{
  "issues": [
    {
      "tool": "bandit",
      "severity": "HIGH",
      "message": "Использование eval",
      "file": "test.py",
      "line": 10
    },
    {
      "tool": "flake8",
      "severity": "LOW",
      "message": "Неиспользуемый импорт",
      "file": "main.py",
      "line": 3
    }
  ]
}
```
